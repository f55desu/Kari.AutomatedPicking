# WB Photo Report

Скрипт получает количество фото в карточках WB по списку `nmID` и сохраняет результат в Excel.

## Что нужно

1. Python с библиотекой `openpyxl`
2. WB API token категории `Content`
3. `.env` файл рядом со скриптом

Пример `.env`:

```env
WB_API_TOKEN=your_wb_content_token_here
```

## Запуск

Обычный запуск с ручной вставкой списка:

```powershell
python wb_photo_report.py
```

Если команда `python` не находится, можно использовать готовый лаунчер:

```powershell
.\run_wb_photo_report.ps1
```

После запуска вставьте список `nmID` и завершите ввод пустой строкой.

Запуск с указанием txt-файла:

```powershell
python wb_photo_report.py --input-file articles.txt
```

Запуск с явным именем выходного файла:

```powershell
python wb_photo_report.py --output report.xlsx
```

## Что будет в Excel

- Лист `Найдено`: `Артикул WB`, `Количество фото`
- Лист `Не найдено`: список `nmID`, которые не встретились в карточках

## Важное замечание

Скрипт делает адресный запрос по каждому `nmID` через поиск `textSearch` в `cards/list` и передает `withPhoto: -1`, чтобы карточки находились независимо от наличия фото. Это медленнее при очень больших списках, но заметно надежнее, чем полный обход всего кабинета на больших каталогах.
